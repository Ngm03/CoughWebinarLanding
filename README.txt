VADIM DOC — лендинг «Ребёнок кашляет → бесплатный вебинар»

ГОТОВАЯ ЛОГИКА
- VSL: полный файл ~7:04, без сокращения.
- Видео H.264 + AAC. vsl.mp4 создан remux-операцией stream copy: без перекодирования аудио/видео и потери качества.
- Статичная надпись в плеере: 3:40.
- Скорости: 1x / 1.5x / 2x / 2.5x.
- До 3:37 (217 сек) нельзя перемотать вперёд дальше реально просмотренного места.
- На 3:37 автоматически открываются чек-лист и вся нижняя часть лендинга.
- После разблокировки состояние сохраняется в localStorage, чтобы при обновлении страницы человек не терял доступ.
- PDF доступен для скачивания.
- Отзывы: свайп-карусель, изображения не обрезаются; нажатие открывает полный отзыв крупно.
- После разблокировки появляется sticky-кнопка регистрации на вебинар.
- Вебинарная ссылка меняется в одной строке.

HOSTINGER / ОБЫЧНЫЙ ХОСТИНГ
1. Загрузите ВСЮ папку vadimdoc_cough_webinar_landing на сервер.
2. Не меняйте структуру assets.
3. В index.html найдите:
   const WEBINAR_URL = 'PASTE_WEBINAR_LINK_HERE';
4. Вставьте свою ссылку регистрации между кавычками.
5. Откройте index.html по вашему домену.

TILDA
1. Папка assets должна иметь публичный URL (например, на Hostinger).
2. Откройте TILDA_CODE.html.
3. Найдите:
   const ASSET_BASE = 'https://YOUR-DOMAIN.COM/PATH/assets';
   и поставьте URL папки assets.
4. Найдите:
   const WEBINAR_URL = 'PASTE_WEBINAR_LINK_HERE';
   и вставьте ссылку регистрации.
5. Скопируйте весь код TILDA_CODE.html в блок T123.

ВАЖНО
- Если хотите протестировать разблокировку заново в том же браузере, удалите ключ localStorage:
  vadimdoc_cough_vsl_unlocked_v1
  либо откройте страницу в режиме инкогнито.
- Отсечка разблокировки в коде:
  const UNLOCK_AT = 217;
- Не меняйте vsl.mp4, если хотите сохранить исходное качество и звук.
